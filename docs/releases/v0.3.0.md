# CrossAgents v0.3.0 更新报告

**发布日期**：2026-11-23  
**版本跨度**：`v0.2.43` → `v0.3.0`

`v0.3.0` 是 CrossAgents 从单机桌面客户端迈向**跨平台多节点远程控制 + 原生 Tauri 壳 + 现代视觉体系**的一个里程碑版本。

---

## 一、核心新特性：跨平台远端节点控制（「这边的大脑 + 那边的手脚」）

现在可以把一台常开的中心 Hub 与任意多台 **Windows / macOS / Linux** 机器连在一起，**直接用本机配好的模型与订阅号池（Antigravity / Claude / Codex / Cursor 等），去操作另一台不同系统的机器上的文件和终端命令**——目标机无需安装大模型 CLI、无需登录 AI 账号、也无需配置代理。

### 1. 远端节点守护进程与命令集（CLI）
- **新增 `crossagents node run --hub <url> --token <cad_...> [--cwd <dir>]`**：
  - 轻量无头节点守护进程，支持 Windows / macOS / Linux（包括无桌面的 Linux 服务器）。
  - 走标准 **HTTP + SSE 反向长连接**（`/v1/node/stream` + `/v1/node/results/{call_id}`），自动兼容 **SSH 隧道**、**内置 iroh 打洞隧道** 与局域网直连，无需在目标机开放入站端口。
  - 断线自动指数退避重连（1s → 2s → 5s → 10s → 30s），凭据被吊销时立即退出。
  - Windows 下执行命令自带 `CREATE_NO_WINDOW`，不弹黑框。
- **新增远端控制 CLI 子命令**（终端与脚本、Bot 均可直接调用）：
  - `crossagents node list` — 查看所有在线节点（OS / 架构 / 默认 Shell / 工作目录）
  - `crossagents node exec <node> [--cwd <dir>] [--timeout <secs>] -- <command...>`
  - `crossagents node read / write / edit / ls / search <node> ...`

### 2. Agent 原生 MCP 跨机工具
- 每个 agent 会话自动挂载 7 个跨平台远端节点工具：
  - `node_list`、`node_exec`、`node_read`、`node_write`、`node_edit`、`node_list_files`、`node_search`
- 模型通过 `node_list` 获取目标机的操作系统与默认 Shell 后，会自动使用对应平台的命令（例如在 Windows 调 PowerShell、在 macOS/Linux 调 sh/bash/zsh）。

### 3. 安全隔离与界面可见性
- **严格凭据隔离**：`DeviceKind::Node` 凭据（`crossagents device add <名字> --kind node`）仅允许访问 `/v1/node/*` 节点通道，访问其他所有 Hub API 一律返回 `403 Forbidden`；在设置 → 设备页吊销后连接立刻断开。
- **设置 → 设备页新增「在线远端节点」视图**：直观显示已连接的远端节点（系统图标、主机名、架构、默认 Shell、工作目录与连接时间），未接入时展示一键接入指引。

### 快速上手（两步接入第二台机器）
```bash
# 1. 在中心 Hub 所在机器签发节点凭据
crossagents device add linux-bot --kind node

# 2. 在目标机器（Linux / macOS / Windows）启动节点守护进程
crossagents node run --hub http://127.0.0.1:8321 --token cad_xxx --cwd /srv/my-bot
```

## 二、桌面端架构升级：全面切换至 Tauri 原生壳

- **Tauri 2.0 正式接管 Windows / macOS 构建与发布流水线**，安装包体积大幅缩小（Windows NSIS 安装包约 25 MB），支持 Ed25519 签名自动更新。
- 统一自定义无边框标题栏与系统托盘菜单，修复 Windows 右键托盘菜单闪退与 macOS 更新包签名校验问题。

---

## 三、Windows 体验深度打磨：彻底告别终端黑框闪现

- **隐藏 ConPTY 宿主**：为 `launch::direct`、常驻守护进程 `runtime-host` 以及 `agy` 账号/额度探测统一引入 Windows 隐藏 ConPTY（`CreatePseudoConsole`），让 agent 及其子进程树共享不可见控制台。
- **绕过 Git for Windows 套壳启动器**：Windows 下自动将 `PATH` 中的 `...\cmd\git.exe`（46 KB wrapper）解析直连到真实的 `...\mingw64\bin\git.exe`，消除每轮对话拍快照（`snapshot::take`）和刷新 Git 视图时的 30ms 黑框闪现（未安装 Git 时自动平滑回退）。

---

## 四、视觉与交互升级（macOS / shadcn 风格）

- **全新配色系统**：默认强调色从偏 AI 感的靛紫色切换为克制的 **macOS System Blue**，同步升级 **`墨 · shadcn`** 主题，并修复侧边栏搜索框聚焦描边偏移问题。
- **侧边栏底部个人卡片 + 按厂商分组号池浮层**：
  - 将原密集的竖条号池与状态栏整合为现代桌面端风格的**个人资料卡片**（Hub 同步头像 + 角标连接状态点 + 昵称/版本 + 紧凑号池胶囊 `4/5` + 设置入口）。
  - 悬停/聚焦号池胶囊展开**按厂商分组浮层**（Claude / Codex / Antigravity / Cursor / CodeBuddy），组内可用账号置顶、耗尽/未登录/风控账号自动置灰沉底。
- **个人资料云端同步**：昵称与头像自动同步至 Hub（`<home>/profile.json`），跨设备访问同一 Hub 保持一致。

---

## 五、Antigravity (`agy`) 与编辑器细节增强

- **上下文窗口占用统计**：`antigravity_native` 驱动现支持从单步 `step_update.usage` 追踪实时上下文占用，并按模型映射上下文窗口上限（Gemini 1M / Claude 200K / GPT-5 & Codex 272K 等）。
- **图片消息 ACP 模型与档位自动匹配**：修复发送图片切至 `agy acp` 时因组合模型名（如 `gemini-4-neon-medium`）与 ACP 基础模型名（`gemini-4-neon`）不一致导致的 `not offered` 警告，并自动同步推理档位。
- **Markdown 文件链接区间支持**：修复点击 `:33-64`、`:33:1-64:10` 等行号区间链接时报 `not found` 的问题，直接打开文件并定位到起始行。
- **工具详情对齐**：统一 `antigravity_native`、`cursor_native`、`gemini_native` 的 `ToolDetail` 结构，并与 Hub 终端分层（`user` / `agent` / `system`）打通。
